# Hon Viet Thu Thanh

Hon Viet Thu Thanh is a Unity 3D tower defense + strategy game inspired by Plants vs. Zombies lane defense and TFT-style tactical placement. The game uses a Vietnamese mythology/history theme with a low-poly 3D isometric camera style.

## Tech Stack

- Unity 6000.4.8f1
- C#
- 3D URP
- Git + GitHub
- Git LFS

## Team Module Ownership

- Dev1: Grid & Hero Placement
- Dev2: Enemy & Wave System
- Dev3: Combat & Hero Skills
- Dev4: GameManager, UI & Rules
- Dev5: Scene, Art, Prefab, Audio & Integration

## Important Rules

- Do not push directly to main or develop.
- Each developer works in their own module folder and scene.
- Do not edit another developer's scene without permission.
- Do not edit Assets/Project/Shared without notifying the team.
- Scene_Integration.unity is controlled only by Dev5 or the leader.
- Pull develop before starting work each day.
